## 🚀 Featured projects

**[olist-data-platform](https://github.com/srxkatsumi/olist-data-platform)** — Modern ELT pipeline (Airflow, Airbyte, dbt, Snowflake, Metabase) built to simulate a real migration from a legacy SQL environment to a cloud-native architecture. Phase 1 (ingestion + transformation) complete; documents the real environment issues hit and fixed along the way.

**[smart-wallet-ml](https://github.com/srxkatsumi/smart-wallet-ml)** — Automated ML pipeline that runs daily via GitHub Actions: an adaptive ensemble of classifiers forecasts short-term directional price movement, validates its own past predictions, and re-weights itself based on recent accuracy. Built with strong AI pair-programming support; I own the design decisions and have debugged every production incident end to end.

**[climate-adaptive-ml](https://github.com/srxkatsumi/climate-adaptive-ml)** — Early-stage companion project applying the same adaptive-ensemble approach to daily climate forecasting across three climate regimes, testing whether temporal-decay weighting beats static baselines.
